## Project-Specific Instructions

### Build & Test

```bash
# Install dependencies
npm install

# Build the TypeScript code
npm run build

# Run tests (builds first, then runs tests)
npm test

# Run in development mode
npm run dev

# Lint the code
npm run lint
```

### Key Guidelines

- **Always use npm**, not pnpm or yarn
- **Run `npm test` before committing** to ensure nothing is broken
- **Use English** for all new code, comments, and documentation
- **Follow the i18n pattern** for user-facing strings (use `t()` function)
- **Import with .js extensions** for ESM compatibility (e.g., `'./lib/utils.js'`)

### File Locations

- **Commands**: Add new CLI commands in `src/commands/`
- **Utilities**: Add shared logic in `src/lib/`
- **Templates**: Add templates in `src/templates/en/` and `src/templates/es/`
- **Tests**: Add tests in `__tests__/` with `.test.js` extension

### When Modifying Commands

1. Update `src/index.ts` to register the command
2. Create the command handler in `src/commands/<command>.ts`
3. Add necessary i18n keys in `src/lib/i18n.ts`
4. Write tests in `__tests__/`

### Bridge File Changes

When modifying bridge file generators in `src/lib/bridges.ts`:
1. Update the generator function
2. Update `BRIDGE_FILES` map if adding new editors
3. Test with `agent-ctx update` in a test project
